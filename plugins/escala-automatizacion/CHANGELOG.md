# escala-automatizacion — qué cambia para vos

## 0.1.0 — 2026-09-27
- **Paquete nuevo, para automatizar procesos**: «cuando entra un mail con X, que se cargue en Y y me avise por WhatsApp».
- **n8n** (7 skills de czlonkowski/n8n-skills): código JavaScript y Python, expresiones, configurar nodos, validar flujos y patrones de workflows. Si tenés conectado el MCP de n8n, Claude lo usa mejor.
- **`n8n-manychat`**: ManyChat e Instagram/WhatsApp dentro de n8n. **`zapier-make-patterns`** y **`workflow-automation`**: cuándo conviene Zapier, Make o n8n, y cómo armar flujos que no se rompan.
- **`ci-cd-and-automation`**, **`entra-app-registration`** (registrar una app en Microsoft 365/Entra) y **`mcp-builder`** (construir tu propio conector MCP).
- **3 agentes**: `automation-architect` diseña el flujo desde el relevamiento hasta la prueba, `data-engineer` arma pipelines de datos y `deployment-engineer` ayuda a publicarlos.
- Cada pieza externa trae su `ORIGEN.txt` y la licencia de su autor.
